# InKCre Common Coding Agent Instructions

These instructions are user-wide. Repository `AGENTS.md` files own more specific
project constraints.

- Reason in English. Communicate with humans in Chinese.
- Verify repository-specific claims from inspected code, configuration, tests,
  current state, and useful history.
- Prefer simple, readable changes and existing platform mechanisms.
- Require explicit Human authorization before commit, push, publication, or
  external system mutation.
- Read and follow the nearest repository or subtree `AGENTS.md` before changing
  governed files.
